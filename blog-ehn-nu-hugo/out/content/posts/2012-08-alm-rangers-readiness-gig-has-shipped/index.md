Together with todays announcement that Visual Studio 2012 as been officially released, the ALM Rangers have also simultaneously shipped (“sim-shipped”) a massive set of solutions for feature gaps and value-add guidance for the ALM community.

[http://blogs.msdn.com/b/visualstudioalm/archive/2012/08/15/welcome-to-visual-studio-2012-alm-rangers-readiness-wave.aspx](http://blogs.msdn.com/b/visualstudioalm/archive/2012/08/15/welcome-to-visual-studio-2012-alm-rangers-readiness-wave.aspx "http://blogs.msdn.com/b/visualstudioalm/archive/2012/08/15/welcome-to-visual-studio-2012-alm-rangers-readiness-wave.aspx")

You can find a complete list of ALM Ranger solutions here: \
[http://msdn.microsoft.com/en-us/vstudio/ee358787](http://msdn.microsoft.com/en-us/vstudio/ee358787 "http://msdn.microsoft.com/en-us/vstudio/ee358787")

I have been a part of the [Team Foundation Build Customization Guide](http://vsarbuildguide.codeplex.com/), which have been updated with new features in Visual Studio 2012, as well as the top requested features from the first version of the guidance. As part of this guidance, we have also developed the Community TFS Build Manager, a Visual Studio extension that simplifies a lot of tasks when working with TFS Build. It now exist both for [Visual Studio 2012](http://visualstudiogallery.msdn.microsoft.com/cfdb84b4-285e-4eeb-9fa9-dad9bfe2cd10) as well as for [Visual Studio 2010](http://visualstudiogallery.msdn.microsoft.com/16bafc63-0f20-4cc3-8b67-4e25d150102c). I’d like to thank the rest of the team for doing such a great job, especially [Mike Fourie](http://www.freetodev.com/) who has been driving the entire project in style!

I am proud to be a part of the [ALM Rangers group](http://msdn.microsoft.com/en-us/vstudio/ee358786.aspx), everybody involved put in a considerable amount of their (already limited) spare time to produce top quality guidance and tools for the community.
