Jakob has published three books in the area of Visual Studio ALM:

---

**[Continuous Delivery with Visual Studio 2015](http://www.amazon.com/Continuous-Delivery-Visual-Studio-2015/dp/1484212738) (*Apress - 2015*)**\
(With [Mathias Olausson](http://blogs.msmvps.com/molausson/))

*This book is the authoritative source on implementing Continuous Delivery practices using Microsoft’s Visual Studio and TFS 2015. Microsoft MVP authors Mathias Olausson and Jakob Ehn translate the theory behind this methodology and show step by step how to implement Continuous Delivery in a real world environment.*

[![](http://ecx.images-amazon.com/images/I/41iofLZjgDL._SX327_BO1,204,203,200_.jpg)](http://www.amazon.com/Continuous-Delivery-Visual-Studio-2015/dp/1484212738)

**[Pro Team Foundation Service](http://www.amazon.com/Team-Foundation-Service-Experts-Voice/dp/1430259957/) (*Apress - 2013*)**\
(Co-authored with [Mathias Olausson](http://blogs.msmvps.com/molausson/), [Mattias Sköld](http://mskold.blogspot.se/) and [Joakim Rossberg](https://www.apress.com/index.php/author/author/view/id/2328))\
 *Pro Team Foundation Service gives you a jump-start into Microsoft’s cloud-based Application Lifecycle Management platform, taking you through the different stages of software development. Every project needs to plan, develop, test and release software and with agile practices often at a higher pace than ever before.*

[![Pro Team Foundation Service (Expert's Voice in .NET)](https://images-na.ssl-images-amazon.com/images/I/51G1XJldIIL._UY250_.jpg)](http://www.amazon.com/Team-Foundation-Service-Experts-Voice/dp/1430259957/)

**[Team Foundation Server 2012 Starter](http://www.amazon.com/Team-Foundation-Server-2012-Starter-ebook/dp/B00AC1HDKM) (*Packt Publishing - 2012*)**\
(Co-authored with [Terje Sandstrøm](http://geekswithblogs.net/terje/))\
*Team Foundation Server 2012 is Microsoft's leading ALM tool, integrating source control, work item and process handling, build automation, and testing.*

This practical "Team Foundation Server 2012 Starter Guide" will provide you with clear step-by-step exercises covering all major aspects of the product. This is essential reading for anyone wishing to set up, organize, and use TFS server.

[![](http://ecx.images-amazon.com/images/I/51IP2cmjheL._SX398_BO1,204,203,200_.jpg)](http://www.amazon.com/Team-Foundation-Server-2012-Starter-ebook/dp/B00AC1HDKM)
